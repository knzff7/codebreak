# Публикация CODEBREAK на Render

## Файлы для Git

Добавьте в репозиторий файлы приложения и конфигурации, включая `index.php`, `Dockerfile`, `render.yaml`, `.dockerignore` и `.gitignore`. Не отправляйте `rooms.json`: там находятся PIN-коды, токены возврата и другие данные игровых комнат. Не добавляйте и архив или папку `heliohost-upload` — это устаревшая подготовка для другого хостинга.

Если используете GitHub в браузере и загружаете файлы вручную, не выбирайте `rooms.json`, `rooms.json.lock`, `rooms.json.tmp`, `.freebuff` или папку `heliohost-upload`. `.gitignore` автоматически действует при обычной работе через Git, но не ограничивает ручную загрузку файлов через сайт GitHub.

## Создание сервиса

1. Создайте репозиторий GitHub и отправьте в него файлы проекта.
2. Войдите в Render и выберите создание нового **Blueprint** либо **Web Service** из GitHub-репозитория.
3. Если Render предложит Blueprint, выберите `render.yaml`. Для Web Service выберите Docker как способ сборки.
4. Оставьте бесплатный план и создайте сервис. Render соберёт `Dockerfile` и выдаст адресу вида `https://имя-сервиса.onrender.com`.
5. Откройте адрес сервиса. При первом запуске должна загрузиться главная страница CODEBREAK.

В репозиторий не нужно записывать пароли, токены или ключи. Для текущей конфигурации дополнительные переменные окружения и база данных не требуются.

## Важное ограничение бесплатного тарифа

Игра пока хранит комнаты в JSON-файле. Бесплатный Web Service Render не сохраняет изменения файловой системы между некоторыми перезапусками, остановкой и повторным развёртыванием. Поэтому опубликованная игра запускается, но комнаты и партии могут сброситься. Не используйте её для важных игр, пока хранилище не будет перенесено во внешнюю базу данных или другое постоянное хранилище.
