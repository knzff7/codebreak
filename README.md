# CODEBREAK

Браузерная игра на угадывание PIN для 2–6 участников, включая максимум двух ботов.
Приложение находится в `index.php`; комнаты и партии сохраняются в `rooms.json`.
Новые комнаты получают свободный трёхзначный цифровой код от `000` до `999`.
Начальные нули сохраняются: например, `007` нужно вводить целиком.

## Запуск

Нужен PHP 7.4 или новее. Для локального запуска из папки проекта:

```sh
php -S 127.0.0.1:8000
```

Откройте http://127.0.0.1:8000. На хостинге PHP должен иметь право записи в папку
проекта: сохранение использует временный JSON-файл и отдельный файл блокировки
`rooms.json.lock`. Блокировка охватывает чтение, изменение и запись, а готовый
JSON заменяет предыдущий файл целиком. Внешние редакторы JSON должны работать
при остановленном приложении.

## Возврат в игру

- В том же браузере сохраняется ключ возвращения. Перезагрузка восстанавливает
  прежнего игрока, а повторное подключение не занимает новое место.
- При потере сессии можно ввести код комнаты в форме входа; браузер использует
  сохранённый ключ этой комнаты.
- На другом устройстве или после очистки данных браузера нужны код комнаты,
  прежний ник и свой секретный PIN. Этот способ доступен, пока игрок не выбыл.
- Выбывший игрок может вернуться наблюдателем через прежнюю сессию или сохранённый
  ключ браузера. Исключённый хостом участник не восстанавливается в текущую партию.
- Новые участники входят только в лобби. Имена в комнате не должны повторяться.
  Старые дубликаты хост может удалить кнопкой крестика.

## Правила

Очередь определяется порядком игроков при начале партии и сохраняется во всех
раундах. Выбывшие пропускаются. Потеря сети не удаляет участника и не меняет его
позицию; при необходимости хост может исключить отсутствующего игрока.

Человек подтверждает совпадения вручную, сервер проверяет ответ по сохранённому
PIN. Выбывшие видят всю историю: автор, цель, попытка, число совпадений и раунд,
без ограничения числа записей прямо в карточках игроков. Новые атаки и ответы
обновляются каждые 2 секунды; в центре показаны последняя атака и текущий игрок.
Отдельного общего списка атак нет. В конце появляется плашка победителя.
Секреты активных соперников в API состояния не раскрываются.

Сохранённые комнаты старого формата поддерживаются. `rooms.json` оставлен на
прежнем месте; его доступность по HTTP зависит от настроек вашего веб-сервера.

## Проверки

```sh
php -l index.php
python tests/test_game.py php
node tests/test_ui.cjs
```

Вместо `php` во второй команде можно указать полный путь к исполняемому файлу.
API-тесты запускают временную копию приложения с отдельным JSON и не меняют
сохранённые партии проекта. Проверяются повторный вход, заполнение комнаты,
исключение, возврат по ключу/PIN, очередь, наблюдение, завершение игры и боты.


## Хранение данных и публикация

Комнаты и игровые PIN-коды хранятся в `rooms.json`. Этот файл содержит секреты активных и сохранённых игр: он исключён из Git и из Docker-образа. Для локальной игры PHP должен иметь право записи в папку проекта. На Apache файл данных и его временные копии закрыты правилом в `.htaccess`.

Чтобы опубликовать игру на Render, отправьте файлы проекта в GitHub и создайте на Render новый Web Service из этого репозитория. Render соберёт приложение по `Dockerfile`; отдельные команды сборки и запуска задавать не нужно.

Бесплатный Web Service Render использует временную файловую систему. Комнаты могут сброситься при перезапуске, остановке или повторном развёртывании сервиса. Не используйте эту конфигурацию для хранения важных партий без внешнего постоянного хранилища.

Перед отправкой проверьте, что `rooms.json` не добавлен в Git. Если файл уже был закоммичен, одного `.gitignore` недостаточно: удалите его из индекса Git, сохранив локальную копию, прежде чем отправлять изменения.
